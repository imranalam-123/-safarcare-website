# SafarCare website demo

A responsive, single-page car-booking website concept with a proposed complimentary ambulance assistance section.

## Run locally
1. Extract `safarcare_website.zip`.
2. Open `index.html` in Chrome, Firefox, Edge, or Safari.

No build tools or dependencies are required.

## Publish for a public link
### Netlify Drop (quickest)
1. Visit https://app.netlify.com/drop
2. Sign in or create a free Netlify account if prompted.
3. Upload the extracted `safarcare_website` folder (or drag the `index.html` file if the uploader accepts files).
4. Netlify will provide a public URL that you can share with friends.

### GitHub Pages
1. Create a GitHub repository and upload `index.html`.
2. Open repository Settings → Pages.
3. Select deployment from the main branch/root folder and save.
4. Share the generated GitHub Pages URL once deployment completes.

## Important limitations
- This is a front-end demonstration only. Booking details are not sent to a server and no real driver booking is created.
- No payments, driver dashboard, authentication, database, live pricing, location tracking, or dispatch are integrated.
- The ambulance section is a proposed service, not an active dispatch service. Before advertising free ambulance availability, arrange qualified providers, funding, dispatch coverage, eligibility terms, and a reliable staffed emergency contact process.
- For an emergency in India, call 112, or 108 for ambulance services where available. Do not rely on this demo for emergency assistance.
- Replace the brand name, contact details, terms, privacy policy, service area, and legal information before public commercial launch.
